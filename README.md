# EventLedger

EventLedger is an event-driven financial transaction processing system build with Go. 

The goal of this project is to build a reliable backend system that processes financial events using message-driven architecture, ensuring message durability, idempotent processing, transactional consistency, and fault tolerance.

## Project Overview

EventLedger simulates a deposit processing system similar to real-world financial platform.

The system will use:

- Go for backend development
- NATS JetStream for reliable message delivery
- PostgreSQL for persistent storage
- Docker for infrastructure management

The main focus of this project is learning and implementing production-grade backend concepts:

- Event-driven architecture
- Message brokers
- Distributed systems concepts
- Reliable message processing
- Database transactions
- Concurrency handling
- Fault tolerance
